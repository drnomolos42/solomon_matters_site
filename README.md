# Solomon Matters — Website

Marketing site for Solomon Matters, a smart home / home automation advisory business serving electricians, builders and ADU developers in greater Los Angeles.

Static HTML/CSS, no build step, no backend.

## Structure

```
index.html              the live page
assets/css/styles.css   Modernist design-system tokens + components
assets/css/site.css     page layout (grid, header/footer, responsive)
assets/img/logo.png     logo asset
design_handoff_solomon_matters_homepage/   original design handoff docs (reference only, not deployed)
```

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static file server.

## Design reference

See `design_handoff_solomon_matters_homepage/README.md` for the full design spec, tokens, and open questions (phone number, licensing disclaimer wording, pricing figures to verify).
