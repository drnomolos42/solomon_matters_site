Before you order

Update the BIOS first

B850 boards ship ready for Ryzen 9000, but flashing the latest BIOS (Q-Flash Plus, no CPU needed) fixes memory and stability issues. Then turn on EXPO in the BIOS so the RAM runs at its rated 6000 MT/s.

Is 16 GB enough for mods?

Yes. Sims 4 loads only the custom content actually in use, so even a huge Mods folder rarely pushes it past about 10 GB. DDR5 costs several times what it did a year ago. If more memory is ever needed, replace both sticks with a 2×16 GB kit.

Plan the case layout

The A3 ships without fans. Put three intake fans on the bottom, one exhaust fan at the rear, and mount the ATX power supply at the front. The air cooler is 157 mm tall, which fits under the case's 165 mm limit.

Don't forget Windows

The list doesn't include an operating system. Budget for a Windows 11 Home license, or install Windows and activate it later.
